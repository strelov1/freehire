# Out of scope

Ideas this project decided not to take, one file each, with the reason and the condition that
would reopen them. Read it before proposing or picking up something new: a request that matches
an entry here gets the entry's link instead of a second investigation.

Each file:

- a title naming the idea, and one line saying what the project does instead;
- `## Why this is out of scope`: what was checked, with measurements where there were any;
- `Revisit if …`: the concrete change that would reopen it;
- `## Prior requests`: the issues and pull requests that asked.

A decision that is later reversed is deleted here, not left to contradict the code.
