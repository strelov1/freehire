# A "related projects" or "alternatives" list in the README

This project does not list other job services in its README, mutually or otherwise.

## Why this is out of scope

freehire builds a job aggregator, not a directory of job tools. GitHub already has curated
"awesome" lists for that, and a list here would need keeping current with services we do not run
and cannot vouch for. The README stays about freehire.

Revisit if a project becomes a dependency or an integration of freehire itself, in which case it
belongs in the documentation of that integration, not in a list.
