## Provider identities and reads

Catch Talents uses numeric company and posting IDs. Page through the listing by offset and hydrate unseen descriptions. The public index has no company ID.

Talentglade uses tenant subdomains and public IDs. Verify counts and the returned employer and posting ID. A closed posting can return a different active vacancy.

Employment Hero uses organisation slugs and stable job IDs. Its paged API includes descriptions. Public links use the friendly ID, and detail-page metadata links to the employer page.
