**talentstorm traps** (`talentstorm`, by ontavio, at `<site>.talentstorm.de`; live-verified 2026-10-25 across 127 labels from the German harvest and Common Crawl — 122 with offers, 1,355 offers, mostly industrial mid-sized employers, ~5% technical):
- **The career site reads `api.talentstorm.de/api/v1/joboffers/basic/<site>`, which answers only a request whose `Origin` is the site itself.** Without it, and for a label no tenant holds, it answers 401 "Authentication Required", so a 401 is a plain failure, never `ErrBoardGone`. Paged it serves 10 offers; `?pagination=false` returns the whole list in one answer, which is the listing (`fullBoardListing`). The `Accept: application/ld+json` variant that states `hydra:totalItems` is unreachable through the shared client, which always sends `application/json`.
- **An offer carries its assembled body (`description`), workplaces, employment and offer type**, so nothing is hydrated. Offer type 6 is an open application ("Initiativbewerbung", 75 of 1,355) and is dropped; `speculativeApplication` is NOT that signal — it is set on ordinary positions too. Type 4 (Praktikum) maps to `internship`, 7 (Freelancer) to `contract`, a position's `ft`/`pt` to full/part time; Minijob, Ferienjob, apprenticeship and study types stay `""`. Talentstorm records no work arrangement.
- **`transparencyOfPay` states a wage range with no currency**; it is kept as EUR only where every workplace is in Germany or Austria, and dropped elsewhere. The API names no company; the prober takes the headquarters workplace's label.
