**rexx traps** (`rexx`, rexx systems' recruiting portals; live-verified 2026-10-25 across the 152 portal hosts Common Crawl names — 119 answer a listing, 101 with postings, 3,126 postings, largely healthcare, retail and public sector):

- **The board is the portal BASE: a host, optionally with a path** (`zieglersche-portal.rexx-recruitment.com`, or `jobs.newyorker.de/karriere` for a portal on the employer's own domain). The adapter lists `<base>/stellenangebote.html?start=<offset>`, 100 postings a page; the walk ends on a page with no new posting and fails the board if any page fails or the 100-page bound is reached (`crawlAllPagedLinks`). The largest portal measured (newyorker) has 918 postings.
- **The listing template is per tenant** (a table on one, cards on another), so postings are read from their permalinks, `/<slug>-<lang>-j<id>.html`, which every template shares. The slug and language are decoration: the portal serves an id under any slug, so the id is the identity. **The permalink host is NOT checked**: a portal on the vendor host routinely links its postings on the employer's own domain (`jobs.zieglersche.de`). Every link carries a per-request `?sid=`, which is dropped — kept, each page would look entirely new and the walk would run to its bound.
- **A posting is read from its schema.org JobPosting**, whose `description` already holds the task/profile/benefit sections (`responsibilities`/`qualifications`/`jobBenefits` repeat them). 176 of 178 sampled posting pages carry one; `voss` renders none, so its postings come back as unreadable markers — the harvest prober reads one posting page and skips such a portal. `hiringOrganization.name` is the PORTAL's name ("… GmbH Jobportal" on a third of portals), so the catalogue's employer is used. No portal sampled sets `jobLocationType`; `TELECOMMUTE` would map to remote, nothing else is set structurally.
- **The Atom feed is not the listing.** `rss_generator-rss0.php?unit=<unit>&lang=de` lists the same postings, but `unit` is a per-portal name the root page does not always link, and the feed carries no body.
