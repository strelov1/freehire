**concludis traps** (`concludis`, a German ATS at `<tenant>.concludis.de`; live-verified 2026-10-25 across 47 tenant hosts in Common Crawl — 28 serve the list, 23 have openings, 2,778 positions):

- **Every tenant serves its complete list at one fixed address**, `/prj/lst/a181a603769c1f98ad927e7367c7aa51/GesamtlisteOffenePositionen.htm` — the same hash on every tenant — paged under `?page=N` at a size the tenant picks (15 or 25), stating its extent in `.stellensum` ("46 Stellen gefunden", "1 Stelle gefunden", "Derzeit haben wir keine offenen Stellen."). A page past the end repeats the last one. The walk must collect exactly the stated number (it did on all 23) or the crawl fails (`fullBoardListing`).
- **A tenant that publishes on its own site redirects the list there** (`edeka` → `verbund.edeka`); leaving the tenant's host is `ErrBoardGone` with the destination in the message. An unknown label also resolves (wildcard DNS) and redirects onto the vendor's marketing site, which answers 404.
- **A tenant can redirect single POSTINGS to its own site while the list stays on concludis.** The first production crawl (2026-10-25) read 1,772 positions and marked 988 unreadable: `edeka-rr` 668/668, `smurfitkappa` 239/251 and `bofrost-at` 28/28 redirect every posting (`www.smurfitkappa.com/de/people/jobad#job=/prj/shw/…`), `transdev` routes some to its subsidiaries' sites. No request variant (`ie=1`, `iframe=1`, a Referer) stops the redirect. Where the landing page states a JobPosting it is read; where it does not, the posting is dropped, not marked — a marker would recur every run and hold the board's unseen sweep shut, and a dropped posting was never stored. A page on the tenant's own host missing its JobPosting is still a marker.
- **The body and the employer are on the posting page's JobPosting**; a group tenant posts for subsidiaries (`hhla` → METRANS Rail). `employmentType` is a string or a list; only a single value is mapped, `OTHER` never. No sampled posting (90) states `jobLocationType`.
- **The list page's keywords meta names the employer** as its first entry on 28 of 28 tenants (or the bare label, which names nobody) — that is the prober's company name; one tenant pads it with byte-order marks.
