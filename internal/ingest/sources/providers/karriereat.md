**karriere.at traps** (`karriereat`; measured 2026-11-22 from the crawl host, host2):

- **Plain client, no proxy, no Scrapling tier.** The jobs sitemap and `/jobs/<id>` answer 200 to a plain curl with or without a browser User-Agent. 25 of 25 random sitemap postings answered 200 with a schema.org `JobPosting`, read at one a second. A posting that no longer exists answers 404 (id 9000001); an id below the live range answers 301.
- **robots.txt allows everything.** `User-agent: *` has an empty `Disallow`; only `BLEXBot` and `AhrefsBot` are barred. The sitemap the adapter reads, `/static/sitemaps/sitemap-jobs-https.xml`, is one of the files robots.txt names (the others are companies, salaries, professions and landing pages).
- **The sitemap is the whole catalogue in one file**: 13,248 `/jobs/<id>` URLs (1.5 MB), ids 7,611,468 to 10,039,926, each with an RFC 3339 `lastmod`. `lastmod` moved on 255-1,805 postings a day over 2026-11-13..20, so it is the last change, not the first publication; the adapter orders newest-changed first and takes the first-published time from the page's `datePosted`. No pagination, no cap.
- **Everything is read from the page's `application/ld+json` JobPosting**: `title`, HTML `description` (the full body), `datePosted` (RFC 3339 with offset), `employmentType` (a list, `FULL_TIME` seen), `jobLocation` (a list of `PostalAddress` with locality, region and `addressCountry`), `identifier.value` (the id), `hiringOrganization.name`, and `baseSalary`. The pages carry no `validThrough`.
- **Not every posting is Austrian.** The sitemap also holds postings placed from Italy (Autogrill, `addressCountry: IT`, a different, older-style JSON-LD with no `identifier` and no `employmentType`); the country is taken from the address, never assumed. The adapter keys on the sitemap id, not on `identifier`, for that reason.
- **Salary is a floor.** The page states it as "ab 2.789,33 € monatlich" / "ab 48.520 € jährlich" and the JSON-LD carries one `value` with `unitText` `MONTH` or `YEAR`, so only `SalaryMin` is set (EUR only; another currency is dropped).
- **No IT signal.** The JSON-LD names no category, so `IsTechHint` is unset and the pipeline's catalogue filter decides.
- **Titles are German** (with a few English ones, and Italian postings). `classify` reads the German IT vocabulary only in part; the share of titles outside IT that resolve no category is high, as for other non-English boards.
- **Pace and cost.** One page request a second, two workers; a run reads at most 900 new postings (newest first) plus a 300-posting backlog window, ~20 minutes inside the scheduler's 2,400 s budget. A cold start of ~13k postings drains over about ten runs; steady state is the day's new postings (a few hundred).
