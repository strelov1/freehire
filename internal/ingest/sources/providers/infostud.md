**Infostud traps** (`infostud`; live-verified 2026-10-28 from a residential IP):

- **Serbia's largest general board, not an IT one.** 3,171 open postings from 1,852 employers on 2026-10-28, ~230 published per weekday (a dozen at weekends). The site's own "IT" category holds 75 (2.4%) and telecommunications 19 more; only "IT" (category 5) sets `IsTechHint`, since telecommunications is field technicians and call-centre sales as much as engineers. 61 postings are remote (1.9%) and 108 hybrid (3.4%); 885 (28%) state a salary.
- **The search is GraphQL, and its host's robots.txt disallows it.** `graphql.poslovi.infostud.com` serves `/graphql` (where `searchResults` lives) and `/public/graphql` (which lacks it), and its robots.txt disallows `/graphql` and `/api`. So the listing is the server-rendered page the site itself serves, `/oglasi-za-posao?page=N`, whose `__NEXT_DATA__` carries the same `initialSearchResults` the API answers: 30 postings a page, `totalPrimaryItems` and the page's own `page` number. ~63 KB a page gzipped (528 KB raw), ~106 pages a walk.
- **A page past the last answers PAGE 1 again**, with HTTP 200 and 30 postings. The walk reads the total on page 1, fetches every page it implies, and stops early only when a page names a different `page` than the one asked (the search shrank during the walk). Any page failing fails the crawl. The default order puts paid placements first, so it is not newest first; the hydration budget sorts by the card's `onlineViewDate`.
- **The work arrangement is the card's two flags**, `workFromHome` and `hybridWork`. Neither set is silence, not on-site. The card's `location` repeats it as prose ("Beograd | Hibrid", "Beograd | Terenski rad", a bare "Rad od kuće"), which is stripped from the place. The card's `expirationDate` ("13.11.2026") is the last application day; the posting page's own `job.expirationDate` ("15.11.2026.", trailing dot) says the same when present and is preferred.
- **The body is the posting page's `job.textAd` (HTML)**, in its own `__NEXT_DATA__`; the page's JobPosting ld+json carries only a one-line stand-in. The slug is cosmetic (`/posao/x/y/<id>` answers the same page). A closed posting answers 200 with `status: "archive"` and `active: false`; an unknown id answers 404. A posting with no `textAd` (an image-only ad) yields nothing. **Every `textAd` carries a hidden tracking watermark**, `<li style="display:none;">Reference: <token></li>`, plus an empty hidden `<div>`; the sanitizer keeps the element and drops the style that hid it, so elements hidden by an inline `display:none` are removed first (`infostudDropHidden`).
- **Salary is `job.unformattedSalary`, in hundredths**: `{"from":"4000","to":"6500","additional":"hourly","type":"gross","currency":"USD"}` is 40-65 USD an hour (the page's own label reads "bruto 40 - 65 USD (satnica)"). Period (`monthly`/`hourly`) and net-or-gross are stated on every one; most Serbian salaries are quoted net. Job has no net/gross field, so the site's label leads the body ("Plata: neto 900 - 1.400 EUR (mesečno)"). A posting stating one figure has no upper bound. Currencies seen: RSD, EUR, USD.
- **Abroad postings exist** (Germany, Montenegro, Croatia — "Nemačka - Hanover", "Podgorica (Crna Gora)"), so the country is `FallbackCountries: rs` only and the location dictionary decides.
- **Hydrating and coverage-gated**, 1,000 posting pages a run at one request a second, freshest first, stopping 5 minutes before the deadline. The default `freehire/0.1` User-Agent is served on both page kinds.
