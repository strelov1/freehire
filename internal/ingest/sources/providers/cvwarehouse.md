**CVWarehouse traps** (`cvwarehouse`, a Belgian ATS whose customers are mostly in Belgium and Portugal — the Portuguese ones include IT consultancies such as agap2IT, Adentis, Team IT, Bee Engineering and KCS IT; live-verified 2026-10-27 — 144 companyGuids in six Common Crawl snapshots, about 115 sites with vacancies, about 2,340 listed vacancies):

- **The board is the companyGuid** (lower case): every site is `jobpage.cvwarehouse.com/?companyGuid=<board>`, which redirects to the site's default language. ONE page carries every listed vacancy: a list item (`a.jobLink[data-jobid]` inside a `div[data-item-collection]` whose `data-filter-*` attributes hold country, city, region, work type and schedule) and a hidden detail block (`div[data-jobdetail-job-id]`) with the title and the full body in `.jobDescriptionText`. No request is spent per vacancy. The listing has no date; the vacancy page's JobPosting has one, but that page is the whole site again (0.3–0.6 MB), so it is not read.
- **A site can be SECTIONED**: the home page lists only `?section=<guid>` links and each section is its own page of vacancies. 40 of 52 sites that looked empty on their home page were this. The adapter reads the home page plus every section it links and de-duplicates by id; any page failing fails the board (`fullBoardListing`). The apply form also carries `section=`, so only links to the listing path `/` count.
- **Only LISTED vacancies are taken.** The page also carries detail blocks for vacancies the customer does not list on its site (KCS IT: 9 listed, 94 blocks, all with a future `validThrough`). They are left alone.
- **An unknown companyGuid answers 200** with the platform's "Job niet beschikbaar" page. A career page renders `<body class="home">`; anything else fails the board rather than reading as an empty site.
- **The country filter is a NUMBER** — the position in an alphabetical English country list (22 Belgium, 176 Portugal, 154 Netherlands). `cvwarehouseCountries` lists only the ids checked against real cities. An unknown id leaves the country to the location dictionary.
- Standing open applications ("Candidatura Espontânea", "Spontane sollicitaties") are dropped by title. One host serves every site, so the provider is paced (`cvwarehouseRequestInterval`).
