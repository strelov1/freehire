**Tenstreet traps** (`tenstreet`; live-verified 2026-10-20 from a residential IP):

- **The board is the carrier's numeric `company_id`**, which every posting link carries (`pulse.tenstreet.com/share_app_show_active_jobs.php?active_job_id=…&company_id=774&portal_user_id=1`). The listing is the carrier's Pulse profile, `share_app_index.php?company_id=<board>`: one unpaginated server-rendered page (357 postings for the largest carrier sampled) whose cards link every open posting, some carded twice. An unknown id answers HTTP 200 with an empty profile — no carrier name — which the adapter reports as `ErrBoardGone`. `portal.tenstreet.com/share_app_index.php`, which the posting page's back button names, is a 404. The carriers' other apply host, `intelliapp.driverapponline.com/c/<slug>` (2 of 40 sampled links), names no company id, sits behind a Cloudflare 429, and is not recognised.
- **The posting is a JSON array in an inline script** (`var active_job_array = [...]`), one row per hiring location, each repeating title, description and requirements — a nationwide posting is ~1.8 MB. **`portal_user_id=1` is load-bearing**: without it, and for a posting asked for under another carrier's id or closed, the page answers `active_job_array = null` under HTTP 200. A null page is deferred, never stored.
- **Some postings have no body at all** (`job_description` and `job_requirements` both null — 4 of Dupré Logistics' 64, one an "EDI Integration Analyst"). That is the platform's answer, so they are yielded body-less rather than deferred forever. `job_requirements` is otherwise often an empty `<strong>&nbsp;</strong>` placeholder and is dropped; `job_pay` was null on every posting sampled.
- **Geography is US states, stated structurally**: a row is `select_states` (state code in `value`) or `zip_radius` (state in `state`, a ZIP prefix in `value`), and the page plots every row on a US map as `US-<state>`. `Countries` is therefore `us`, and `Location` lists the distinct codes plus `US` — the bare codes alone would be misread, since `IN`, `GA`, `DE`, `IL`, `AR` also spell countries. No posted date, work mode or employment type is published.
- **Slow and uneven, never refused**: 357 posting pages at four in flight averaged ~2.2 req/s with no refusal, but 7 took over 10 s and one 78 s. Hence `NewLongTimeoutClient`, four detail workers and a run-wide pacer at ~2 req/s. A HydratingSource, so steady state is one listing request per board.
- **Not an IT platform**: almost entirely trucking carriers (drivers, mechanics, dispatch). Nothing sets `IsTechHint`.
