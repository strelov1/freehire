**Inploi traps** (`inploi`; live-verified 2026-10-31, company slugs `compass` 2197 postings and `haven` 122; `puregym` publishes a key but no segment id; an unknown slug answers 404):

- **A board is the company slug** on `https://www.inploi.com/company/<slug>`. That URL redirects to the employer's own career host, and the search page there (`/search`) embeds React Router streamed flat-reference state. Decode its indexed keys and values: the page SDK names the public `pk_` API key, and its `jobSearchFilter` with key `segment_ids` names the positive numeric `defaultValue` (Compass 248, Haven 497; live-verified 2026-11-11). Nearby strings or other filters are not segment evidence. The listing is `GET https://api.inploi.com/search/results` with header `x-publishable-key`. `per_page` above 100 is **422**. The walk fails unless every page's row count matches the pagination and the distinct ids equal `total`, which is what earns `fullBoardListing`. A missing or null `data` fails the crawl. An unknown segment answers **200 with total 0**, the same shape as an empty segment, so the adapter does not claim `emptyBoardListing`. A search page that names no segment fails the crawl (`puregym`).
- **The list has no body.** Title, employer (`company_name`, else the catalogue company), place, `employment_type` (`FULL_TIME` / `PART_TIME`; `OTHER` is silence), `created_at`, and pay are on the row. `location_type` `LOCATION` is a place, not a workplace, so it sets no work mode; `REMOTE` / `HYBRID` / `ONSITE` do. Pay is stored only when `pay_mask` is not true and `pay_display` is not false, the period is `ANNUALLY` / `MONTHLY` / `DAILY` / `HOURLY`, and a currency is named. The body is the career host's `/job/<id>` page, a schema.org `JobPosting` ld+json block, fetched only for postings the catalogue lacks, at most 400 a run.
- **The detail budget must reach past rejected or unreadable postings.** Half goes to the listing's unseen head and half to a backlog window with a random start. A fixed first 400 can remain unseen forever; rotating by the hour also skips parts of the backlog on the scheduler's two-hour cadence. Random sampling avoids that cadence dependency without promising a bounded revisit time. Every listed id still reaches the seen predicate so the pipeline can track deferred work.
- **Job links on `www.inploi.com/company/<slug>/job/<id>` are the same board.** The customer host (`jobs.compass-group.co.uk`) is not itself a board: the slug is what the next crawl resolves.
