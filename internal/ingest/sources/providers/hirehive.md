**HireHive traps** (`hirehive`; live-verified 2026-10-31 from a residential IP, tenants `amcsgroup` 59 postings, `redo` 14, `empyrean-solutions-llc` 2, `hirehive` 1):

- **A board is the tenant label** on `<tenant>.hirehive.com`. The public jobs API is `GET /api/v2/jobs?page=&page_size=` and needs no key. An unknown label answers **404**. Page size 100 is honoured (`amcsgroup`'s 59 arrived in one page with `has_next_page: false`). The walk fails unless the distinct ids equal the first page's `total_items`, which is what earns `fullBoardListing`. A page that omits `total_items`, `has_next_page` or `items` fails the crawl. An emptied board was not observed live, so the adapter does not claim `emptyBoardListing`; a stated total of 0 with an empty `items` is still a successful empty read.
- **Each item is the whole posting.** `description.html` is the body (`description.text` is rebuilt into HTML when html is absent). A posting whose `hosted_url` is not an https URL on that tenant's host fails the whole board crawl. `country.code` is a structured country. `type.type` maps `FullTime` / `PartTime` / `Contract`|`Temporary`|`Freelance` / `Internship` / `Fellowship`; `experience.type` maps `EntryLevel` / `MidLevel` / `Senior`, and `NA` is silence. There is no structured workplace field.
- **Salary is `compensation_tiers`**, and only a tier that names `interval` (`year`/`month`/`day`/`hour`), an ISO currency and a positive whole-number bound. A tier typed `none` with null bounds is "not stated" (58 of 59 on `amcsgroup`). `information` is prose (one Empyrean tier's OTE sat there beside a different structured range) and is not read. The API names no employer; the catalogue company stands, and the prober reads `Jobs at …` from the careers page title.
