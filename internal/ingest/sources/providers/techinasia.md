**Tech in Asia traps** (`techinasia`; live-verified 2026-10-15):

- **The edge refuses any client that names itself.** `www.techinasia.com` (AWS ELB) answers 403 to `freehire/0.1 (+https://freehire.me)`, to `Mozilla/5.0 (compatible; freehire/0.1)` and to a bare `Mozilla/5.0` — `robots.txt` included — and 200 to a full desktop Chrome string, so the provider is a `browserUASource`. `robots.txt` disallows nothing under `/jobs`. The static bundle host and Algolia answer any UA.
- **The listing is the public Algolia index `job_postings`, and the key lives in the app bundle.** `/jobs/search` names `static.techinasia.com/assets/v5/app.<8 hex>.js` (~2.5 MB), whose config carries `algolia:{apiKey:"…",appId:"219WX3MPV4"}`. Both rotate with deploys, so they are read on every run. The key answers with no Referer; it refuses `/settings` (403), so nothing about the index's configuration is readable.
- **One hit is the whole posting, body included** — 274 postings in one 1,000-hit page, `exhaustiveNbHits: true`, 250 in Indonesia. A run is three requests, no hydration. The walk still pages to `nbPages` and FAILS unless the distinct ids read equal `nbHits`, which is what earns `fullCatalog` (the provider is swept by source).
- **Not an IT board.** 37 employers; by the index's own `position`, ~140 of 274 are software/IT (Software Engineer 34, QA & Testing 23, Web Development 22, IT Engineer 20, Enterprise Software & Systems 10, Mobile 7, DevOps 2) and the rest marketing, sales, teaching. The catalogue filter judges each title; seven unambiguous positions set `IsTechHint`. `Data & Analytics` and `Hardware & Embedded Systems` do not — they held a newsroom "Researcher" and a "Pilot Drone". One outsourcing firm (SIGMATECH) is a third of the board.
- **The salary fields are money, not flags** (a third party read them as flags on 2026-09-23): 161 of 274 carry a real range (`7500000`-`8000000` IDR, `8000`-`11000` SGD for a senior PM), 113 an all-zero range meaning "not stated". No period is stated; the site's own salary copy and every observed amount are monthly, so the period is `month`.
- **`external_link` is set on 18 of 274, and not all of them are the posting's own.** Darwinbox, Trakstar and Airtable links are per-posting; one noteforms.com form serves several roles and `forms.gle` is a redirector. A link more than one posting shares, or one through a shortener, keeps the Tech in Asia page instead — a shared URL would read as one posting to every URL consumer.
- **`published_at` is a zone-less `2006-01-02 15:04:05`**, read as UTC. A remote posting may carry `city: null`; it is stored as "Remote" with no country.
