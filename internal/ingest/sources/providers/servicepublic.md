**Choisir le service public traps** (`servicepublic`; live-verified 2026-10-28 from a residential IP):

- **The French civil service's own board** (State, local authorities, public hospitals): 53,975 open postings, ~1,200 going online a day, every trade. The government's "Numérique" domain marks its IT roles and sets `IsTechHint`. robots.txt names no crawler and allows everything but `/wp-admin/`.
- **The sitemap is stale**: its 59.6k offer URLs are 2022-2023 references whose pages answer "Offre dépubliée". **The RSS button points off-site and `/feed/` answers a WordPress 500.** The listing is the offer list itself, `/nos-offres/page/<n>/`, 25 cards a page, newest first. Its `<title>` states the page count ("page 2 sur 2160"). The `admin-ajax.php` `get_offers` action answers 80 KB instead of the page's 4.5 MB, but only ever the first page.
- **A listing page is ~190 KB compressed (4.5 MB raw)**, because it embeds every search filter, so a whole walk (~2,200 pages) is too much for one run. A run reads the HEAD (newest first until a page holds no posting the catalogue lacks, at most 150 pages) and then a WINDOW of 600 later pages whose offset advances 50 pages an hour around a cycle of the page count rounded up to the next 500. The window is wider than the offset moves in twelve hours, because a run can come late when the scheduler is saturated, and a wall-clock offset that outran the window would step over the pages between two runs. That cycle must NOT be the exact page count or depend on the head, since both move between runs and an offset taken modulo a moving value jumps to an arbitrary page (CodeRabbit caught it before the merge). The cycle comes round in ~50 hours, and the provider declares a 120 h `sweepGrace` (two turns), because a window cut short by a failed page, or a very late run, can miss a page for one turn. A failed head page fails the crawl; a failed window page only ends the window.
- **A card names the employer** (`Employeur :`), so the adapter is `CoverageGated`. The identity is the URL's reference (`…-reference-2026-2453798/`, or `MENJ-30-2026-49681` for the education ministry); the title slug is cosmetic.
- **The body is the page's `col-left rte` column** ("Vos missions en quelques mots", "Profil recherché", …), with its "Afficher la suite" buttons removed. The JSON-LD `Description` is the same text with its structure flattened, and its `baseSalary` is prose ("Non renseigné"), so neither is read. The JSON-LD gives the title, the employer (a plain string), `industry` (the domain) and `datePosted` in `dd/mm/yyyy`. A withdrawn posting answers 200 with the title "Offre dépubliée", which means gone. "Télétravail possible" is Oui / Non / Non renseigné, mapped hybrid / on-site / nothing.
- **The run is bounded**: one request a second, two detail workers, at most 600 new posting pages a run, and hydration stops 5 minutes before the deadline. The ~54k cold catalogue takes ~90 runs, newest first.
