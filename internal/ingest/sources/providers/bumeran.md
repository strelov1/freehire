**Bumeran traps** (`bumeran`, Argentina — Bumeran and ZonaJobs, both Jobint/Navent; live-verified 2026-10-27 from a residential IP and the crawl host):

- **Bumeran and ZonaJobs are ONE pool.** `POST /api/avisos/searchV2` answers the same 8,941 postings on either host (`x-site-id: BMAR` or `ZJAR`); a ZonaJobs-born posting keeps its own 7-digit id, a Bumeran-born one a 10-digit id, and either host's search returns both. The two `sitemap_avisos_*.xml` files (6,310 + 2,630) partition the pool by origin and sum to it. So one adapter covers both sites; there is no `zonajobs` provider.
- **The edge (Cloudflare) answers 403 to an API request without the site's own `Referer`** — any User-Agent, ours included, passes with it. `robots.txt` names no Claude agent and disallows only `recientes=`/`relevantes=` page URLs, not the API.
- **The search carries everything but a usable body**, 100 results a request (it honours 200), newest first with `sort=RECIENTES`: title, employer, `confidencial`, place, `modalidadTrabajo`, `tipoTrabajo`, area/subarea ids. Its `detalle` is the body with every tag and line break removed ("PUERTO MADEROBUSCAMOS"), so the body comes from `GET /api/candidates/fichaAvisoNormalizada/<id>` (HTML `descripcion`, `requisitos.salario`, `requisitos.experiencia.minimo` in months, `estado`). A gone posting answers 404 or `estado: "vencido"`. New postings only (`HydratingSource`), at most 1,200 a run at one request a second, taken in the search's own order (ids do not order the pool: a ZonaJobs id is 7 digits), and hydration stops 5 minutes before the run's deadline so the writes still land. Any listing page failing fails the crawl: the walk is ~90 requests, and a partial one would let the company-scoped sweep close postings it never reached.
- **20% of the pool hides its employer** (`confidencial: true`, shown as "Confidencial"), plus a few descriptive names ("Importante Empresa de Retail", a bare "Consultora"); they are dropped before any request. The rest is mostly agencies (Adecco, Grupo Gestión, Randstad); 861 postings arrive through Navent's HiringRoom plans (`origenAviso: HIRING_ROOM`), which is why the adapter is `CoverageGated`.
- **`modalidadTrabajo: "Presencial"` is the form's default** (85% of the pool, including titles that say "Home office" or "(Remoto)"), so only `Remoto` (1.8%) and `Híbrido` (13.6%) are mapped.
- **Salary is structured, monthly, gross and unlabelled as to currency**: `salarioMinimo`/`salarioMaximo` with `frecuenciaPago: "por Mes"`. Posters type placeholders (1, 2, 11111, 99999, a range opening at 1), so both ends must reach 100,000 before it is stored as ARS a month.
- **Area 19 ("Tecnología, Sistemas y Telecomunicaciones", 414 postings, 4.6%) sets `IsTechHint`**, except its subareas Telecomunicaciones (107, field work) and Data Entry (2608).
