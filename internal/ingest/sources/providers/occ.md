**OCC Mundial traps** (`occ`; live-verified 2026-10-15, transport and scope re-measured 2026-10-21):

- **The listing is behind Cloudflare now; the posting JSON is not.** By 2026-10-21 every listing page answered the "Just a moment..." challenge (403, `cf-mitigated`) to the prod host and the crawl host alike. Through the rotating proxy a plain request passed 4 of 10 pages and the Scrapling tier's impersonating fetcher 7 of 10; its browser from the crawl host's own IP read 10 of 10 (~6 s a page). The walk needs every page, so the listing is a `scraplingProviders` row in `browser` mode with no proxy, while `oferta.occ.com.mx` answered 5 of 5 direct and keeps a plain client (`occSplit`).
- **Every category is a board** since the catalogue became broader than IT: the site lists 23 (`/empleos/trabajo-en-<slug>/`, the slugs in its own category links). Only `tecnologias-de-la-informacion-sistemas` (`occITBoard`) sets `IsTechHint`; the rest are left to the classifier. A board hydrates at most `occMaxNewPerBoard` (2,000) new postings per run, since the first run meets the whole catalogue as new.

- **The search pages refuse the project's bare User-Agent.** `www.occ.com.mx/empleos/…` (allowed by robots.txt, which disallows only account, help and `/rest` paths) answers a plain 403 to `freehire/0.1 (+https://freehire.me)`, to a bare `Mozilla/5.0` and to the project string with `Mozilla/5.0` appended, and 200 to `Mozilla/5.0 (compatible; freehire/0.1; +https://freehire.me)` — so the provider is a `compatibleUASource`, still naming us. The posting JSON host answers either. A third party saw a geo-scoped Cloudflare challenge from non-Mexican egress (career-ops, 2026-09-04); none was seen from Brazil on 2026-10-15.
- **The board is a CATEGORY, the site's own.** `/empleos/trabajo-en-tecnologias-de-la-informacion-sistemas/?page=N` lists the IT category, 20 cards a page: 4,361 postings over 219 pages, page 220 empty. Keyword paths (`/empleos/de-<keyword>/`, career-ops' approach) are a search, not a slice. Only the IT board sets `IsTechHint` (see above).
- **Two cards repeat at the top of every page**, past the last one included (data-id 21367373 and 21375686 all day). The walk ends on the first page adding no NEW id — page 220 carries no card at all. A full walk read **4,360 distinct ids against the stated 4,361**, so the stated total cannot prove the walk and the provider does not claim `fullBoardListing`.
- **The posting page is not the source; the split view's JSON is.** `/empleo/oferta/<id>/` answered `scraping abuse` (403) to every User-Agent after a handful of requests, while `oferta.occ.com.mx/offer/<id>/d/j?ipo=41&iapo=1` (the URL template in the listing's `#hduod` input, `j` for JSON) answers the posting with our own UA: 162 sequential requests, 0 refusals. Its keys are abbreviations: `t` title, `c.cn` employer, `ld` body (HTML), `pt` posted day, `c`/`l` city/state, `smin`/`smax`/`lss` pay, `uwt`/`uet` the work-arrangement and schedule FILTER links (`/empleos/tipo-home-office-remoto` etc.), which are mapped rather than the Spanish labels beside them. The JSON also carries the recruiter's name, phone and relay e-mail; none of it is read.
- **"Empresa confidencial" is a hidden employer**, ~8% of cards (402 of ~4,800 card renders). The card says so, so such a posting is skipped before its JSON is bought: it names no employer to file it under.
- **Pay**: `lss` is the display ("$45,000 - $50,000 Mensual") and the only place the period is stated; no currency is named anywhere, and on this Mexican board the `$` is the peso. 121 of 162 sampled showed a monthly range; the rest read "Sueldo no mostrado por la empresa" or "Si el reclutador te contacta podrás conocer el sueldo" with zero bounds.
- **No ATS overlap observed**: `uaext` (an external apply URL) was empty on all 162 sampled postings, so Job.URL is the OCC posting page (the detail's `ur` without its tracking query) and there is no coverage gate.
