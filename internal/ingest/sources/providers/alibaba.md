**Alibaba traps** (`alibaba`; live-verified 2026-10-15):

- **One portal, every business.** `POST https://talent.alibaba.com/position/search` with `channel: "group_official_site"` lists the experienced-hire (社招) postings of Alibaba Cloud, Taotian, Cainiao, Lazada, Amap and the rest — 4,165 on the day; the business is only the title's prefix ("阿里云智能-…"). Campus hiring is campus-talent.alibaba.com, a separate site, not read. No `robots.txt` (a JSON 404). Any User-Agent.
- **The CSRF check is stateless double-submit**: a self-minted `XSRF-TOKEN` cookie matching the `X-XSRF-TOKEN` header is served; no session or bootstrap request.
- **`pageSize` is clamped to 500 while the offset still advances by the size ASKED for**: `pageSize=1000, pageIndex=3` answers rows 2000-2499, so a walk asking for 1,000 silently skips half the catalogue. The adapter asks for exactly 500.
- **Most rows state no category, so the row cannot be the filter.** 2,391 of 4,165 carry `categories: null`, including plainly technical ones ("AI Agent研发工程师"). The `subCategories` filter still selects them: the 18 codes under 技术类 (130) from `POST /category/list` match 1,488 postings, of which 627 state no category. The parent code alone (`categories: "130"`) matches only 5. A row that DOES state a category must be a 技术 one, or the crawl fails as a filter the search stopped honouring.
- **The category is the platform's, not a guarantee**: it includes data-centre and warehouse operations roles (仓储运营专员, 高级消防工程师) the business files under technology. `IsTechHint` follows the dedicated-category rule all the same, because `classify` cannot read the titles: over the 1,488 technology titles it resolved a category for 29, `IsTech` for 9 and `ConfirmedNonTech` for 1; over the other 2,677, 35 / 1 / 2.
- **Every talent.alibaba.com deep link redirects to the portal home**, in a real browser too. `talent-holding.alibaba.com/off-campus/position-detail?lang=zh&positionId=<id>` — the same platform's holding-company site — renders any posting id, a Cainiao or Taotian one included, so that is Job.URL.
- **Locations are Chinese city names only** (`workLocations: ["杭州","北京"]`, `regionEnNameMap` empty, in `language: "en"` too). `cncity.go` maps the ~90 names the catalogue uses to English and a country; Tokyo, Madrid, Seattle and Seoul are among them, so an unmapped name keeps its spelling and states no country rather than being assumed Chinese.
- **The bodies are plain text in the row** (`description`, `requirement`); `experience.from` is a structured minimum in years. Three requests read the technology category, ~15 s.
