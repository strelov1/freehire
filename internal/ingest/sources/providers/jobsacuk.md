**Jobs.ac.uk** (`jobsacuk`).

- **First-party routes only.** Host2 received HTTP 200 for [robots.txt](https://www.jobs.ac.uk/robots.txt) on 2026-11-22. The wildcard rules disallow `/job/feedback/` and `/enhanced/fp/`. The adapter uses the public [unfiltered search](https://www.jobs.ac.uk/search/) and its posting links. The advertised sitemap redirects to a separate origin and is outside this crawl.
- **Use both public sort orders only when needed.** Search reports its total in `.job-count` and renders job links inside `#job-listings`. Date Placed and Closing Date both use 25 results per page and a one-based `startIndex`. The site coerced a requested page size of 100 to 25. The primary order is Date Placed. An unreadable result page can be recovered only if the Closing Date walk yields a union of exactly the reported count. A changed total or duplicate within a sort discards that snapshot and retries once, starting with Closing Date. Repeated drift or an incomplete union fails before any hydration. On 2026-11-23 the first scheduled run observed the reported count increase from 2,566 to 2,567 by offset 51.
- **Host2 enumeration on 2026-11-22.** Each sort reported 2,720 results across 109 offsets and returned 2,695 distinct references. Date Placed returned an HTTP 200 interstitial at offset 1451. Closing Date returned one at offset 751. Each order had 25 references the other lacked, and the combined set matched all 2,720 without count drift or duplicates within either order.
- **The job reference is stable across title changes.** A result links to `/job/<reference>/<slug>` with a three-letter, three-digit reference. The reference is the external ID. The slug stays in the destination URL.
- **Read the posting's JobPosting JSON-LD.** Host2 read full structured details on nine of ten sampled posting URLs. One returned a 200 interstitial with no JobPosting and remains unreadable. The site returned 404 for an unknown reference. The adapter retains unreadable identities on a partial failure and fails if no attempted detail answers.
- **Closing dates are inclusive.** The advert displays a calendar date, serialized as midnight in `validThrough`. The adapter preserves the date. It reads structured countries and salary, including quoted decimal amounts. It maps a single declared full-time or part-time schedule. Fixed-term appointments alone say nothing about hours, and the board advertises all professions.
- **Hydration is bounded and paced.** One request per second, two detail workers, up to 600 new details in listing order and 200 from a rotating backlog. Known postings are refreshed by identity. The adapter uses the ordinary sweep scope because a detail deferred by the budget may be a stored posting due for recheck.
