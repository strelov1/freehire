**Turijobs traps** (`turijobs`; live-verified 2026-10-27 from a residential IP and the crawl host):

- **The posting pages sit behind Akamai bot management, which holds a plain request open without ever answering** (from the laptop and the crawl host alike, after a handful of requests); the Scrapling tier's impersonating `http` fetcher is served from the crawl host's own IP, no proxy. `robots.txt` names no Claude agent and disallows only admin/template paths.
- **The listing is `/es-es/sitemap/active-offers.xml`, which Akamai does not hold**: 2,498 postings on 2026-10-27, one set — the `pt-pt` and `es-mx` editions list the same ids. It carries only URLs, `/<locale>/oferta-trabajo/<place>/<title>/<id>`; the id is the identity and the path names no employer, so only the title half of the gate can be asked before the page is bought.
- **The page's schema.org JobPosting is the posting**: `title`, `description`, `datePosted` (a bare date), `hiringOrganization.name`, `jobLocation` as one Place with `addressCountry` (ES mostly; PT, FR, DO for the chains' resorts), `employmentType` as an ARRAY when present (`["FULL_TIME","TEMPORARY"]`), `baseSalary` EUR a YEAR on some. A page is ~460 KB. **~10% of pages carry no JobPosting** (56 of the first crawl's 600, newer postings among them); the page's `__NEXT_DATA__` (`props.pageProps.offerData.offerDetail`: title, plain-text description, `publicationDate`, `location.cityName/regionName/countryISO`, `company.brandName`, `isBlind`) always holds the offer and is read instead; a `isBlind` offer hides its employer and is not stored. Only a 404/410 is read as gone; a page carrying neither counts as NO answer (an Akamai interstitial looks the same), and sitemap URLs off `https://www.turijobs.com` are ignored, so nothing else reaches the fetch tier.
- **Posters are hotel groups and restaurants** (Meliá, Barceló, Hesperia, Vértice); the chains that run their own ATS are left to the coverage gate after the fact, since the gate cannot be asked before the page names them.
- **The run is bounded**: one request a second, two workers, at most `turijobsMaxNewPerRun` (600) unseen pages a run, newest id first, stopping 5 minutes before the run's deadline.
