**Talentsoft traps** (`talentsoft`, Cegid Talent — formerly Talentsoft — the French ATS behind EDF, Safran, SPIE, Sodexo, Geodis, Framatome and much of the public sector; live-verified 2026-10-28: 80 sites with open postings among 106 hosts, ~16k postings — Safran 4,532, EDF 1,993, SPIE 1,321, Framatome 757, the Ministère de l'Économie 737):

- **The board is the careers HOST**: `<tenant>.talent-soft.com`, `<tenant>.profils.org` (the vendor's older domain) or the employer's own (`passerelles.economie.gouv.fr`). Labels carry the tenant's own suffix (`-recrute`, `-career`, `-cand`), so nothing about a host is derivable from the employer. DNS has no wildcard.
- **Read the list with `mode=list` and NO `LCID`.** `/offre-de-emploi/liste-toutes-offres.aspx?all=1&mode=list&page=<n>` is the same path on every site whatever its language. The default view (map or tiles) ignores `page` without a session cookie, and `LCID` FILTERS: a language the site offers but did not publish a posting in hides it (`asadventure-bever` lists 104 by default, 0 under `LCID=1036`). A page past the end silently answers page one.
- **Page size is the tenant's** (5 to 30), so it is read from page one; the total is `#…_Pagination_TotalOffers`, and an empty site renders `#…_NoResult_NoResult` instead (Vinci's group portal lists nothing; its entities' sites do). The list is date-ordered, so a posting published mid-walk shifts pages: the walk is not held to the total exactly (no `fullBoardListing`), but one that comes back below 90% of it fails.
- **No feed, no JSON-LD.** The RSS export stops at 20 items. The body is the posting page's `#contenu-ficheoffre` block, bought for new postings only (≤500 per site per run, none in the last 5 minutes of a run). Labelled fields are `<p id="fld…">`: `fldlocation_joblocation` (often a street address), `fldlocation_location_geographicalareacollection` ("Europe, France, Ile-de-France, Essonne (91)"), and the contract under `fldjobdescription_contract` OR a custom code field (`adsn` files "CDI" under `customcodetablevalue1`). Some tenants (Sodexo) render no `fld` field at all.
- **One search serves at most 1,000 results**, whatever the page size: page 51 of Safran's 20-a-page listing and page 101 of Crédit Agricole's 10-a-page one answer page ONE again. The first crawl (2026-10-28) failed exactly the four sites above it (EDF, SPIE, Safran, Crédit Agricole). A slice stating more is split along a search dimension, and the URL parameters are stateless and combine: `facet_<dim>=<id>`. Sites with a facet panel link each value with the slice's own count (`?changefacet=1&facet_Contract=1044`, `facet_JobFamily`, `facet_JobCountry`). A site without one (EDF) takes the parameters its "show the search URL" link prints: `facet_JobDescription_Contract` for the contract select, and `facet_Country` / `facet_Region` / `facet_Department` for a geographic checkbox, depending on how many ancestors its `aria-labelledby` lists. Form counts cover the whole site, so they vouch for a split only at the top, and deeper splits are checked after the walk. A split may fall 5% short, because a posting filed under no value counts in the total. EDF's 1,997 postings give 1,904 by region, the rest being country-only.
- **A withdrawn posting redirects home under HTTP 200** (`/accueil.aspx`), which is its "gone"; the adapter reads the final URL.
- **One tenant can answer on two hosts** (Dorchester Collection's `dc-careers.talent-soft.com` and `recrutementplazaatheneelemeurice.profils.org` list the same ids), and since a posting is namespaced by its board, seed only one.
- Paced at 1 request a second per site and 3 a second across the provider, because most sites share the vendor's hosting.
