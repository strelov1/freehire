**Just Join IT and RocketJobs traps** (`justjoin`, `rocketjobs`; live-verified 2026-10-28 from a residential IP and the crawl host):

- **One platform, two boards.** justjoin.it is Poland's largest IT board (11,212 offers in its sitemap on 2026-10-28); rocketjobs.pl is its sibling for every other trade (15,881: shops, production, sales, logistics, health). Every justjoin.it offer is filed by its employer under an IT category (data, devops, java, pm, support, …), which sets `IsTechHint`; rocketjobs asserts nothing. The previous `justjoin` adapter read `api.justjoin.it/v2/user-panel/offers/by-cursor`, which began answering 503 from every address in 2026-08 and was removed in #2634; its closed rows were keyed by guid, the new ones by slug.
- **The JSON API is off-limits.** `justjoin.it/robots.txt` disallows `/api/` and `api.justjoin.it/robots.txt` disallows `/` for every agent, so the listing is each site's `/sitemaps/active-jobs.xml` index (one part each, a 307 to the platform's public bucket and back) and the facts come from the offer page, which robots.txt allows. A plain client with the project User-Agent is served from the crawl host; no edge. Any sitemap failing fails the crawl.
- **The sitemap names one URL per offer**: a multi-city offer (Sii's remote data role lists 14 cities) appears once, under its parent slug, so the slug is the identity. Some agencies post the same role as separate offers per city (OTTO Work Force), which role dedup collapses. Nothing in the sitemap names the employer, so the adapter is not `CoverageGated`: pages are picked with `hydrationLanes`, 1,100 freshest plus 300 from a moving backlog, one request a second, hydration stopping 5 minutes before the deadline. A page is ~100 KB compressed (~700 KB raw).
- **The offer is the page's Next.js flight**, an `"offer":{"slug"…}` object whose `body` is a `$N` reference to a text row (HTML). The JSON-LD beside it is the same text flattened and its `jobLocationType` is TELECOMMUTE on on-site offers too, so it is not read. **The sitemap still names an offer for about a day after it expires** (4 of 60 sampled): its page answers 200 with `isOfferActive: false`, which means gone; an unknown slug answers 404.
- **`publishedAt` is the last refresh, not the first posting**: every sampled offer was "published" within the past six days although offers run 30, so it is read as `PostedAt` knowing it moves.
- **Pay is listed per contract type, five times over**: once in the employer's own currency (`currencySource: "original"`) and four times converted into CHF/EUR/GBP/USD; only the original is read. Each carries its type (`permanent` = umowa o pracę, `b2b`, `mandate_contract` = umowa zlecenie, `specific_task_contract`, `any`), `gross` (an employment contract is quoted gross, B2B net) and `unit` (month, hour, day). The structured salary takes ONE range — the employment contract's when there is one, else the first stated — and a "Wynagrodzenie" paragraph at the top of the description states every type with its basis, because the facet has room for neither the contract nor gross/net. ~32% of justjoin.it and ~43% of rocketjobs offers state an amount.
- `workplaceType` is `remote` (~48% of justjoin.it, ~5% of rocketjobs), `hybrid` (43% / 18%), `office` (8% / 68%) or rocketjobs' `mobile` (field work, ~8%, mapped to nothing). `experienceLevel` mid maps to middle. `requiredSkills` go through `skilltag.Canonicalize`; the English level is the `languages` entry for `en` (CEFR). `countryCode` is stated on every offer (a few are DE, SE, IN); `FallbackCountries` is `pl`.
