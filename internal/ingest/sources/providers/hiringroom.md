**HiringRoom traps** (`hiringroom`; live-verified 2026-10-15, across 15 tenants including tatachile, stefaniniitsolutionsperu, grupopetersen, humanbrandconsulting):

- **A board is the tenant label** of `<tenant>.hiringroom.com`. There are two portal layouts. On the legacy one, `/jobs` renders cards. On the newer one, `/jobs` 302s to `/portal`, which lists only featured vacancies as schema.org JSON-LD. Neither page is the list: both render at most the first 20 vacancies.
- **The list is the portal's own pager, `POST /jobs/getVacanciesForPortal/<page>`**, form-encoded `selectedPage=<page>&typePortal=external`. It answers JSON with the page's cards as an HTML fragment (`data.htmlContent`) and the portal's `data.total_vacancies`. It serves both layouts. The same parameters as JSON or as a query string answer `"Los parámetros enviados son inválidos"`, hence the shared client's `PostFormJSON`. Leave out `typePortal` and the page comes back empty with a null total. The walk proves completeness against the total (`fullBoardListing`). A microsite portal (`<tenant>.hiringroom.com/jobs/microsite/<name>`, `typePortal=microsite`) is a different list and is not read.
- **Each card renders its tags twice** (desktop and mobile copies). The tags are icon-keyed picklists: `hr-Clock` gives the schedule (Full-time, Part time, Freelance, Pasantía, Eventual, No especificado), `hr-Company`/`hr-Remote` the work mode (Presencial, Híbrido, Remoto), and `hr-Campus` the level (Junior, Semi Senior, Senior; Jefe, Responsable, Gerencia and other management levels are left unmapped). `hr-Work-area` holds the platform's own area taxonomy, `<area> / <sub-area>`. "Tecnología, Sistemas y Telecomunicaciones" sets `IsTechHint` (TCS Chile 30/32, Stefanini 30/31).
- **The vacancy page has no JSON-LD and no date.** The body is the `div.job-description-content` sections ("Descripción del puesto", "Requisitos", "Beneficios"), each after an `h6` heading. A tenant's catch-all "Postulación en base" vacancy has an empty section: it is read with no body rather than deferred forever. The card's only date is relative ("Hace 7 meses"), so `PostedAt` stays nil. Old vacancies stay listed for years (humanbrandconsulting shows some marked "Hace 3 años").
- `robots.txt` is not served (the path answers the portal page). No metering was seen: humanbrandconsulting's 241 vacancies read in 33 s at the shared 8-way fan-out.
