**Taleo Business Edition traps** (`taleobe`; live-verified 2026-10-20 from a residential IP, not yet from the crawl host):

- **It is NOT Taleo Enterprise.** `taleo` crawls `<tenant>.taleo.net/careersection/<n>` through a session-bound search POST; `taleobe` crawls `<pod>.tbe.taleo.net/<pod><nn>/ats/careers/…?org=<ORG>&cws=<n>`, a different product with nothing in common but the name. Neither adapter can read the other's boards.
- **The board is `<ORG>:<cws>`, never the pod.** The org code names the employer and `cws` one of its career sites (an org may run several; a number it does not have is gone). Org codes are case-insensitive at the platform and stored upper-case. The pod (`phf02`, `tre01`, …) is left out because orgs move: the dispatcher (`tbe.taleo.net/dispatcher/servlet/DispatcherServlet?org=…&act=redirectOrg&redirectUrl=…`) resolves an org to its current pod from any TBE host, and a Common Crawl link on `chp02` already answers from `phg02`.
- **One RSS request per board, body inline.** `/ats/servlet/Rss?org=&cws=` lists the whole career site with `taleo:html-description`, `taleo:reqId`, a display `taleo:location` and (only when the employer attached an address) city/state/country parts. The feed matched the HTML site's "Open Positions" total on every board checked, up to 365 of 365, which is what earns `fullBoardListing`. The largest feed measured is 7 MB raw but ~440 KB gzipped (~2 s), well inside the standard client timeout.
- **"Gone" is a redirect, never a status**: an unknown org lands on `/dispatcher/login.jsp`, a deactivated org (`INACTIVE…` in the redirect chain) on `tbe.taleo.net/errorpages/page_not_found_404.html.en` under HTTP 200, and an unknown `cws` on `rssErrMsg.jsp`. All three wrap `ErrBoardGone`. An org whose harvested `cws` is gone may still be live on another: `DispatcherServlet?act=redirectCws&org=<ORG>` (no `cws`) redirects to its default career site.
- **`taleo:locationState` is not consistent** (`Louisiana` on one org, `US-DC` on another), so only the country code is mapped as a structured fact; the location string is the display label (`Remote, United States`, `Nairobi, Kenya`).
