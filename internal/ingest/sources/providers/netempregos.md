**Net-Empregos traps** (`netempregos`; live-verified 2026-10-27 from a residential IP, the crawl host and the proxy):

- **The crawl egresses through the ROTATING proxy gateway (`proxiedProviders` + `rotatingProxyProviders`).** From both crawl hosts' datacenter IPs every POSTING page answers **200 with the candidate login page** ("Net-Empregos - Login de Candidato"), whatever the User-Agent, while the feeds still answer. The wall follows volume per exit: the fixed proxy exit was served a lone posting and then walled ~40 requests into a crawl (2026-10-28), while the rotating gateway (a fresh exit per request) was served 31 of 40 sequential postings and walled 7 — so a walled answer is asked again, up to three times, each from a fresh exit. The first run (2026-10-27) read 1,500 login pages and stored nothing without one error, so a page that is neither a JobPosting nor the site's "Esta oferta já não está activa" notice is now an error, and a run that meets only those fails. `robots.txt` names no Claude agent and disallows only keyword searches (`?chaves=`), login, contact and favourites. curl's DEFAULT User-Agent is reset at the TCP level, so a hand probe with bare `curl` reads as an outage.
- **ISO-8859-1 bytes, no charset in the Content-Type** (Windows-1252 in practice: "–" arrives as 0x96). Everything is read through `GetText` and decoded as Windows-1252 before it is parsed — the shared getters assume UTF-8.
- **~62k live postings (the search page states 62,022 on 2026-10-27, 18 cards a page, 3,446 pages), and no cheap listing of them.** The search is ordered by REFRESH date (agencies bump constantly: ~600 pages were dated the same day), and its last page is dated 30 days back. The `trovit_all.asp`/`careerjet_all.asp`/`listagem_livre3.asp` feeds `robots.txt` advertises all answer the home page.
- **So the listing is the two crawler feeds**: `Sitemap.asp` is a plain-text list (not XML) of the newest 5,000 posting URLs by id (under a day), `rss.asp` the newest 1,000 (~3 hours) with `dc:creator` (employer), and a description block spelling Categoria / Zona / Data and a truncated body. The id is the URL's first path segment; the slug is cosmetic. The RSS names the employer before the page is bought, so the adapter is `CoverageGated` for the postings it carries, and drops a hidden employer ("Anónimo", ~0.6%) without a request; a posting only the sitemap names is bought blind. A failed RSS costs the gate, not the crawl.
- **A posting leaves both feeds within a day but stays live for 30 days past its last refresh**, and nothing else lists it — `sweepGrace` is 30 days (devglobaljobs' shape). Withdrawn postings linger that long at most.
- **The posting page's JobPosting carries raw newlines inside its strings** (invalid JSON; `ldJobPosting` sanitizes control characters) and a plain-text `description` with `<BR>` breaks that ends with the posting's own URL, which is stripped. `datePosted` and `validThrough` are the RENDER time and thirty days on, so the date is the RSS `pubDate` (none for a sitemap-only posting). `addressCountry` is "PT" on every posting, foreign ones included: the zone is the place — a district, "( Todas as Zonas )" (read as Portugal), "Estrangeiro - <country>" or "Outros Locais - Estrangeiro" (no Portuguese fallback for either). `jobLocationType: TELECOMMUTE` marks remote. A withdrawn or expired posting answers **200 "Esta oferta já não está activa"** with no JobPosting, read as gone.
- **Shares, from the 1,000-item RSS of 2026-10-27**: the four "Informática ( … )" categories 20 (2%, they set `IsTechHint`); "remoto/teletrabalho" in ~1% of the truncated bodies; about half from staffing agencies (Job Impulse 196, Adecco 142, iU Talent 51, Iman 30, Gi Group 24, Randstad 11, ...).
- **The run is bounded, and stops short of its deadline.** One limiter paces every request at one a second; a run reads at most `netempregosMaxNewPerRun` (1,500) unseen postings, newest id first, and stops hydrating 5 minutes before its context deadline. ~330 new ids an hour reach the feeds at the afternoon peak, so the provider needs a crawl every few hours to stay inside the 5,000-posting window.
