**BeeSite traps** (`beesite`; live-verified 2026-10-15, on the Mercedes-Benz, Porsche, Daimler Truck, UKE, Allianz, BKM and BAM search hosts):

- **A board is the tenant's `*.app.beesite.de` SEARCH host**, which is not the career site. jobs.mercedes-benz.com searches through `mercedes-benz-beesite-production-gjb.app.beesite.de`, Porsche through `porsche-beesite-production-gjb`, Daimler Truck through `daimler-truck-beesite-production-gjb`. A host named `…-frontend` or `…-intranet` is a different thing (a portal frontend, or the internal-only jobs: Mercedes's intranet host states 2,399 postings linking to `internal-jobs.app.corpintra.net`). Nobody pastes these hosts, so `atsboard` does not try to recognise them. To find one, read a tenant career page's source for `app.beesite.de`, or Common Crawl's `*.beesite.de`.
- **`GET /search?data=<url-encoded JSON>` is keyless and answers whole records.** `SearchParameters.FirstItem` is 1-based and `CountItem` 100 is served. Leaving out `MatchedObjectDescriptor` returns every field. `SearchResultCountAll` is exact, and `LanguageCode` EN and DE return the same set. The default order paged all seven tenants without a repeat or a gap; no sort is sent. A total that moves mid-walk (Mercedes went 2,755 → 2,761 in minutes) fails that crawl rather than passing a skipped posting as complete.
- **Only some tenants put the body in the record.** Mercedes-Benz carries `PositionFormattedDescription[].Tasks`/`Qualifications`, so its 2,761 postings cost no posting request. Porsche, Daimler Truck, UKE and BKM carry none (asking for the field by name returns nothing), so their body comes from the posting page (`PositionURI`, the branded portal page), read only for postings the catalogue lacks.
- **The posting page's JobPosting is malformed on some tenants.** Porsche's block opens with a stray template token (`entryLevel [{...}]`), so it is read from its first bracket. Its `description` is entity-encoded HTML. A posting handled outside the portal (apply by email) renders no JobPosting at all, and its body is read from `div.jobad-dynamic-html-container` instead.
- **Facets are named, not coded, and per tenant.** `PositionSchedule` reads "Full time", "full-time" or "Full time (part time possible)"; `CareerLevel` "Internship" marks an internship. `PositionLocation` carries `CityName`, `CountryName` and an ISO `CountryCode`.
- **`career-ops` names TKMS, Heckler & Koch, Rheinmetall and Deutsche Bahn beside BeeSite, but none of them is on it.** Their providers read a `subclient` job-board API, server-rendered Nuxt pages, Cornerstone TalentLink and an Avature-backed search respectively. Allianz's tenant (1,052) is entirely insurance-agency sales.
- No metering seen: Porsche's 755 posting pages at the shared 8-way fan-out took 2m46s. Mercedes's 28 search pages took 2m37s, since each 100-record page carries the bodies (~1 MB).
