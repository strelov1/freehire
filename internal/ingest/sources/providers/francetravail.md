**France Travail traps** (`francetravail`; written 2026-10-28 from the public documentation and two open-source clients, then verified with the application's credentials from the crawl host the same day):

- **Measured live:** 173,471 of the service's own offers (`origineOffre=1`) across 101 départements. 59 départements exceed the 1,150-result window (the largest, Rhône 69, holds 5,968). Every first page stated its `typeContrat` aggregation. 7.1% of offers withhold the employer and are dropped. Paris (3,374 offers) read whole by bisection in 39 s, 3,039 kept, 151 with `IsTechHint`, 2,372 with a salary.
- **Keyed, and registered only with both credentials.** The "Offres d'emploi v2" API takes an OAuth2 client-credentials token (`POST entreprise.francetravail.fr/connexion/oauth2/access_token?realm=/partenaire`, scope `api_offresdemploiv2 o2dsoffre`) issued to an application registered on francetravail.io. The token lives ~25 minutes and is cached across the run's boards; a 401 fetches a fresh one once. Without `FRANCE_TRAVAIL_CLIENT_ID` and `FRANCE_TRAVAIL_CLIENT_SECRET` the crawl registry omits the provider, the same rule as `reed` and `usajobs`.
- **An OAuth 400 can be application access, not a broken search adapter.** On 2026-11-11, a direct token request from operator returned `{"error":"invalid_client","error_description":"Client authentication failed"}` with the deployed credentials. The same rejection occurred with either scope alone and without a scope. Every operator environment backup containing the credentials held the same pair, including the 2026-10-29 backup; core's environment files held no replacement. This establishes rejected application authentication, but does not distinguish an invalid secret, disabled application or missing API subscription. Check the existing application's status and its "Offres d'emploi v2" subscription in the France Travail developer portal, then restore valid credentials through the deployment's secret environment. Verify a token and an authenticated search before retrying the provider crawl. Never log the token response or credential values, change scopes speculatively, or reset board health while authentication still fails. After recovery, an approved retry may need its board cooldowns cleared so the run actually visits all 101 départements.
- **The board is a département code** (`75`, `2A`, `971`). An offer has one place of work, so the départements partition the catalogue. The search is `GET api.francetravail.io/partenaire/offresdemploi/v2/offres/search?departement=<code>&origineOffre=1&sort=1&range=<a>-<b>`. Only the service's OWN offers are read (`origineOffre=1`): partner offers are copies from other job boards, several of which freehire crawls itself.
- **The search carries every offer whole, description included**, so a crawl issues no detail request and is not a `HydratingSource`.
- **A query shows at most 1,150 results** (`range` up to `1000-1149`, 150 a page). A département matching more is read in creation-date windows (`minCreationDate` + `maxCreationDate`, both required), split at the midpoint until each fits, down to one minute. The match count is the sum of the `typeContrat` aggregation in `filtresPossibles`. When a page states none, a full page at offset 1,000 is the sign to split. An empty window answers **204 with no body**, which `Client.GetJSONOrNoContent` reads as no results; the ordinary JSON getter would retry it as a dropped connection.
- **An offer may withhold its employer** (no `entreprise.nom`), and such an offer is dropped. The body is plain text and is rebuilt with `plainTextToHTML`. `lieuTravail.libelle` ("75 - PARIS 11") loses its département prefix. Every board is French, so `Countries` is `fr`. ROME codes `M18xx` (information systems) set `IsTechHint`.
- **Salary comes only from the structured `salaire.libelle`**, which states period, bounds and currency in one fixed form ("Mensuel de 1800.00 Euros à 2000.00 Euros sur 12 mois", "Annuel de 26400,00 Euros", "Horaire de 11.88 Euros"); `salaire` is an empty list when nothing is stated. The free-text `commentaire` is never read. A required experience (`experienceExige` "E") stated in years sets `ExperienceYearsMin`. CDI is full or part time as `dureeTravailLibelleConverti` says; CDD, MIS (temporary agency) and SAI (seasonal) are contracts.
- **The pace is one request a second**, a tenth of the documented 10 calls a second an application gets. A whole département pass is about one request per 150 offers plus the splits.
