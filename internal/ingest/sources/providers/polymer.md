**Polymer traps** (`polymer`, a startup ATS at `jobs.polymer.co/<board>`; live-verified 2026-10-24 across the 91 boards remoterocketship apply links and eight Common Crawl snapshots name — 61 live, 216 open postings, 101 of them `Remote`):

- **The board page is behind a Cloudflare challenge; its API is not.** `jobs.polymer.co` answers a plain client 403 "Just a moment...", while the page's own data source, `api.polymer.co/v1/hire/organizations/<board>/jobs` (listing) and `.../jobs/<id>` (one posting with its HTML `description` and a `kind` enum), is unauthenticated JSON. The global `/v1/hire/jobs` wants an API key, so there is no boardless crawl.
- **"Not found" is HTTP 422**, for a board (`no careers_page found`) and a posting (`no job found`) alike — `detailUnreadable` would read it as a failed request, so `polymerNotFound` spells it out: a 422 board is `ErrBoardGone`, a 422 posting is dropped.
- **The pager's `is_last` is only true on a real page.** `meta.count` is the board's posting count and `meta.total` its page count; a page past the end answers an empty list with `is_last: false` and a `next_page`. The walk ends on `is_last` or `page >= total` and fails unless the distinct postings reach `count` (`fullBoardListing`). The largest board measured holds 11 postings on one page.
- **`remoteness_pretty` is a four-value enum**: `Remote`, `Hybrid`, `No remote`, and `Remote friendly`, which says remote work is possible without naming the arrangement and stays `""` (jobspage's enum, word for word). A `Remote` posting with `remote_restriction_country_residency_is_required` names its countries in `remote_restriction_country_list`; one without names none, and its office country is deliberately not used.
