**Cadremploi traps** (`cadremploi`; live-verified 2026-10-28 from the crawl host):

- **France's board for "cadres"** (managers and professionals; Figaro group): ~30k open postings, ~2k touched a day. Every trade: in 49 sampled pages, real-estate franchise networks (CAPIFRANCE alone 7), accountancy firms, recruitment firms (Michael Page, Manpower, Expectra) and ~10% technical roles (.NET, C/C++, data, Wi-Fi). robots.txt names no AI crawler and allows `detail_offre?offreId=`.
- **Cloudflare refuses a plain client from the crawl host on every path, sitemap included** (403, any User-Agent). The Scrapling tier's impersonating fetcher is served from the crawl host's own IP (`http`, no proxy), but about one page in six still draws a 403 at one request a second, and five of six of those are served on a second try a few seconds later. So every request is retried on 403/429/5xx (3 retries, doubling from 3 s); the Scrapling client retries nothing itself.
- **The listing is the paged online-postings sitemap** (`/sitemap/002_job-postings-online-<n>.xml`): 28,386 URLs on page 1 and 1,763 on page 2, though the sitemap index names only page 1. The page past the last answers 404, which ends the walk; any other failure fails the crawl. An entry is only a URL (`detail_offre?offreId=<18 digits>`) and a `lastmod`; the run reads the most recently touched first.
- **Nothing names the employer or the title before the page is bought**, so the adapter is not `CoverageGated`. A posting the pipeline discards unsaved would be bought again on every run, so pages are picked with `hydrationLanes`: 900 freshest plus 300 from a backlog window that moves every hour, at one request a second, with hydration stopping 5 minutes before the deadline. A page is ~230 KB.
- **The body is the page's schema.org JobPosting**: `description` plus `qualifications`. Both are typed by the poster: 31 of 49 sampled were HTML, and the rest plain text with an occasional `<br>`, which is given its paragraphs rather than escaped. An unknown id answers 404. **An expired posting answers 200 with "Désolé, cette offre est expirée" and no JobPosting**, and the sitemap still names it for a while (1 of 15 sampled from its newest entries), so that notice means gone. A page with neither is no answer (a challenge looks the same).
- `baseSalary` (51% of the sample) is always EUR per YEAR, and is stored only with both a currency and that period. `employmentType` `CONTRACTOR` covers fixed-term, interim and franchise/independent postings alike and maps to contract; `OTHER` maps to nothing. No structured remote field exists ("télétravail" is prose), so work mode is left to the dictionaries.
