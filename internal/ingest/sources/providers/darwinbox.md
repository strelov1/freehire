**Darwinbox traps** (`darwinbox`, the HRMS most large Indian employers run, at `<tenant>.darwinbox.in` or `<tenant>.darwinbox.com`; live-verified 2026-10-25 — 140 tenant hosts in Common Crawl, 79 with openings, 5,004 postings; India ~65%, then the Philippines, Malaysia, Singapore):

- **The board is the whole host**: the TLD is the tenant's data region, and one tenant label does not say which. The same host is also the tenant's employee HRMS login, so `atsboard` reads a Darwinbox URL as a board only when it carries a `careers` segment.
- **The listing is `POST /ms/candidateapi/job/alljobs` behind Cloudflare**, which 403s Go's default TLS+HTTP/2 fingerprint and curl's alike and serves the Chrome one from both the laptop and the crawl host — hence the shared `fingerprintHTTP`. It pages at **100 whatever limit is asked for**, states the board total as `job_counts`, and every row already carries the whole description (`jd`), so there is no detail request. A walk that does not add up to `job_counts` fails the crawl (`fullBoardListing`).
- **`jd` is entity-encoded, sometimes twice, sometimes not at all** — per posting, not per tenant (2026-10-29, seven tenants' first pages: 441 once, 5 twice, 6 live HTML). Sanitizing it as served stored literal `<p>` text on every page (freehire report #150), so `darwinboxDescription` decodes first and sanitizes LAST. Stored rows heal on the next crawl: the listing carries the whole body, so the new text moves `content_hash` and `UpsertJob` rewrites the row.
- **An unknown tenant is HTTP 500** `Internal Server Error - Invalid subdomain: <label>`; the fingerprint transport's POST keeps no body, so it reads as an ordinary failure, not `ErrBoardGone`.
- **`emp_type_name` is the tenant's own HR category** ("Permanent", "Probationary", "BRANCH RESOURCE", "P-P8-Probationer-HO Executive" — measured over 2,700 postings), so only a label that states the arrangement is mapped. `is_remote` is 0 by default on tenants that never set it, so only 1 is a statement. `country` is a structured country name.
- **The API names no employer**; the portal page served to a non-browser client is a shell whose `<title>` is the legal entity ("Ather Energy Limited"), which is what `cmd/harvest-boards` stores.
