**Beehire traps** (`beehire`; live-verified 2026-10-31, `actemium` 136 postings, `cegelec` 56, `swde` 8, `beehire` 4, `qplus-consult` 0; `digit-eaux` and an unknown slug answer 404):

- **A board is the career-page slug** on `https://app.beehire.com/career/<slug>` (`careerrss` is the same slug). The public API is `GET /users/getPublicCampaigns/<slug>` and needs no key. One response is the whole listing, which is what earns `fullBoardListing`: the distinct `_id`s must equal `len(campaigns)`. A missing or null `campaigns` fails the crawl. An unknown slug answers **404**. An emptied board was observed live (`qplus-consult`, 200 with `campaigns: []`), so the adapter claims `emptyBoardListing`.
- **Each campaign is the whole posting.** `title` and `description` are objects keyed by the campaign's `language` (`0` English through `6` Italian); the campaign language wins, then `0`, then the lowest remaining key. `fullDescription` is preferred when that pick is non-empty. The body is HTML; a plain-text value is rebuilt into paragraphs. `inviteLink` must be https on `app.beehire.com`, and a missing link is rebuilt from `inviteKey`. A posting that fails that check fails the whole board crawl.
- **Facets are `details.contract`.** `type` maps `contractType_permanent` to full-time, `fixedTerm`/`freelance`/`interim`/`replacement` to contract, and `internship`/`apprenticeship`/`student` to internship. A part-time `duration` (`partTime`, `10h`, `20h`) wins over a permanent type; an internship wins over the duration. `remote` maps `remoteWork_none` / `full` / `partial` to onsite / remote / hybrid. `location.country` is a name (`Belgium`, `Belgique`), not a code. There is no salary and no posted date. The catalogue company stands; the prober reads `employerBranding.companyInformation.name`, then `user.company`.
