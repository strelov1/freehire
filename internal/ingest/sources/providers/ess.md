**ESS traps** (`ess`, the Employment Service of Slovenia's job search, www.ess.gov.si; live-verified 2026-10-29):

- **EURES does not cover it.** The `eures` adapter's `si` board is scoped to the ICT occupation groups, so it held 94 open Slovenian postings against ESS's 3,621; the general catalogue is only here.
- **The search page is an Angular app over a public JSON API** at `apigateway-prod-www-prod.apps.ess.gov.si/iskalnik-po-pdm/v1/delovno-mesto/`, behind a 3scale gateway that wants `user_key` on every request. The key is the one the page's own script carries (`ue_dataFor3ScaleApi_userKey`), not a credential issued to us; if it rotates every request fails and so does the crawl. No cookie, no special User-Agent.
- **The listing is `POST prosta-delovna-mesta-filtri`** with every filter present (an absent array is a 400, and `urejevalniPojem`, the sort, must be a NUMBER: 7 = newest first). `drzave: ["SI"]` is Slovenia, which is why the country is set structurally; without it ~25 vacancies abroad join. `steviloDelovnihMest` restates the total on every page, a page is capped at 2,000, and one of 500 answers in ~8 s, so the adapter runs on the long-timeout client: 8 pages, ~45 s for the catalogue. Pages of 1,000 walked newest first returned 3,621 distinct ids for a total of 3,621. Any page failing fails the crawl (the sweep is company-scoped); so do a page coming back empty short of the stated total, an answer with no total, and an empty catalogue.
- **Two more slices of the same listing add structured facts.** Occupational field `0020` ("Računalništvo, programiranje, IT", 19 vacancies) sets `IsTechHint`; working time `2` ("Krajši delovni čas", 202) is part time, and since `1` and `2` partition the catalogue exactly (3,419 + 202), every other vacancy is full time. A failed slice costs its mark only, and a failed or EMPTY part-time slice states no working time at all rather than calling everything full time. "Določen čas" (fixed term) is not contract work and is not mapped.
- **The body is `GET podrobnosti-prosto-delovno-mesto?idDelovnoMesto=<id>`** (~1 s), read for new vacancies only, newest first, 1,200 a run at one request a second, stopping 5 minutes before the deadline. An id the service no longer holds answers HTTP 200 with the id and a view count only: that is "gone". The body is the duties (`opisDelInNalog`, often an inline list opened by dashes, rendered as a list), expectations, other conditions, competences, a list of the record's facts and how to apply. The record's `prijavaDo` ("10. 11. 2026") is the application deadline, read into `ApplicationDeadline` beside its line in the fact list. `kontaktZaKandidata` — a named person, a phone, an e-mail — is never copied.
- **The listing names the employer**, so the adapter is `CoverageGated` on both answers. Employers are register names ("Creina Lokaterm, proizvodnja peči, d.o.o."), often in capitals; titles are mostly capitals with a pay-grade suffix ("PROGRAMER APLIKACIJ VII/2 (I)") and always end in "- M/Ž", the gender marker the law requires, which is cut. Capitals are kept: a roman-numeral grade does not survive case folding. The place (`krajDM`) is an administrative unit in capitals and is title-cased with Slovenian connectors kept lower ("Šmarje pri Jelšah").
- **`okvirnaPlaca`** is "1.500,00 EUR bruto mesečno" when stated (7 of 42 sampled), a monthly gross pay in euros, kept between 500 and 20,000. There is no remote flag.
