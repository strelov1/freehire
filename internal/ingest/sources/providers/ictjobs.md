**ICTJobs traps** (`ictjobs`; live-verified 2026-11-22 from a residential IP and the crawl host, plain http, no proxy):

- **Switzerland's IT job board, still live**: `www.ictjobs.ch` answers one 301 to the bare `ictjobs.ch`, which is a WordPress site (the earlier "dead" reading was only that redirect). **193 postings** on 2026-11-22, all in nine IT categories: system/network/security/voip 49, software development 36, support/IT services 32, consulting 26, IT security 22, project management 12, sales/marketing 7, IT management 6, AI/ML 3. Not folded into jobs.ch; no other adapter references it.
- **robots.txt** (`User-agent: *`) disallows only `/cms/wp-admin/`; the sitemap is advertised. Plain curl from host2 answered 200 on robots, home and sitemap.
- **The posting set is `/post-sitemap.xml`** (CDATA locs, 193 `/<category>/<slug>/` URLs, nothing else in it); the other sitemaps are pages, tags and blog. The slug is the identity (the page's `identifier.value`, e.g. 201365, is not in the sitemap).
- **Each page's schema.org JobPosting is the whole posting**: `description` (full body, ~2-6k chars), `hiringOrganization.name`, `jobLocation` (one address, country CH), `employmentType` as a list (`FULL_TIME`+`PART_TIME` is typical, so the first decisive value `full_time` wins), `datePosted`, `validThrough`, and `baseSalary` (CHF per YEAR) on about a third of the sampled pages. The page also carries a BlogPosting block, which `ldJobPosting` skips.
- **`jobLocationType: TELECOMMUTE` is ignored**: 7 of 12 sampled postings carry it, including on-site roles at SBB Bern whose text never mentions remote work, so it reads as a site default rather than a statement. The work mode comes from the description dictionary.
- **`IsTechHint` is set on every posting**: the board files each one under its own IT category.
- **Language**: German bodies and titles mostly, English for multinationals (NVIDIA, Logitech). Titles are largely English IT terms with Swiss "(m/w/d)" and "80-100 %" suffixes, so category resolution is expected to be high; the German-only role names (Applikationsspezialist, Informationssicherheitsbeauftragter) are the likely unresolved tail, roughly 10-20% by eye, unmeasured.
- **The run is bounded**: 2 s between requests, two workers, 300 new pages a run (a cold catalogue takes about six minutes). An unreadable page is deferred to a later run, and its identity is kept for the sweep when another detail answered. A crawl fails if every attempted detail is unreadable, even when the sitemap names stored postings that can be refreshed. HTTP 404/410 count as confirmed removals.
