**GoHire traps** (`gohire`; verified live 2026-10-24):

- **It meters a request QUOTA, not a rate, and remembers.** From the crawl host one request every ~1.3s was served 400 times and refused with 429 from the 401st; a residential IP refused at ~270 requests was still refused 30 minutes later. So `gohirePacedGetter` paces at one request per 10s (under 400 an hour), and the first 429 latches the adapter for the rest of the run (`gohire.refused`) instead of letting the shared client's retries spend the quota. Harvest with `-pace 0.1`.
- **Only the trailing 8-character code addresses a site.** `jobs.gohire.io/<anything>-de5jlhjo` and the bare code 301 onto the canonical slug, so `boardIdentity` folds onto the code. An older numeric form (`dexerto-19265`) still appears in crawled links and answers 404.
- **Any listing page failing fails the board**, not just the first — the opposite of `crawlPagedLinks`' salvage rule, because here a later page failing is the quota running out mid-board, and a salvaged first page would leave the rest unseen run after run until the sweep closed it.
- The listing states its own extent (`Page 1 of 3, Total 21 jobs`), ten cards a page under `?page=N`; the posting page's JobPosting carries `jobLocationType` (TELECOMMUTE), `applicantLocationRequirements` as country NAMES, and a structured `baseSalary`.
- `recooty` (`jobs.recooty.com`, seen beside these two in the same remote-job feed) was measured and NOT onboarded: 58 tenants, ~1.3k postings, dominated by insurance-agency "work from home sales agent" listings repeated per tenant, and 25 of 55 sampled postings dated 2023.
