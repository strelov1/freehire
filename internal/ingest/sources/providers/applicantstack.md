**ApplicantStack traps** (`applicantstack`; live-verified 2026-10-20 from a residential IP, not yet from the crawl host):

- **A board is the tenant subdomain, lower-cased.** `<tenant>.applicantstack.com/x/openings` is the listing and `/x/detail/<id>` a posting; hosts are case-insensitive and the same tenant is linked as both `SmartAutoCare` and `smartautocare`. A tenant on its own domain (`careers.<employer>.com/x/detail/<slug>`) is the same application, but no URL rule can name its board, so `atsboard` declines it. `www`, `www2` and `public` are the vendor's own hosts.
- **The listing pages by `?pge=N`, 100 rows a page, and its pager states the whole count** ("Showing 1 - 100 of 282"). The walk fails unless the distinct postings equal that total, which is what earns `fullBoardListing`. A board with no openings renders the table (`#data-table`) with no rows and no pager; a page past the end answers "Invalid page number" with no table; an unknown tenant 302s to `www.applicantstack.com/job-not-found/`, a 200 marketing page with no table. Only the first is read as empty — a page without the table fails the crawl.
- **The listing's columns are the tenant's choice** (Location, Department, Salary Range, County - Territory …), so only the posting link and its title are read there. The posting page's ld+json carries the body, `datePosted` and a structured address; its `title` is a separately configured field that is often null, so the listing's title (what the page itself shows) is used. A gone posting answers 404.
- **`robots.txt` declares `Crawl-delay: 5` and the adapter honours it per board**: every tenant is its own host, so one board's requests are spaced 5 s apart while other boards run alongside. 88 posting pages at 8-way concurrency answered no refusal, so the delay is courtesy, not a measured limit. Hydrating: steady state is one listing request per 100 postings plus a page per new posting; a 282-posting board's first crawl is ~24 minutes.
- **Not an IT platform.** Tenants are mostly small US employers — home care, restaurants, clinics, field services; the catalogue filter judges each title.
