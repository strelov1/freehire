**helixjobs traps** (`helixjobs`, the job portal Perbility runs for its concludis employers at `helixjobs.com`; live-verified 2026-10-25 by walking the whole portal list — 1,001 pages, 25,021 postings, 590 instance ids):

- **The portal is concludis under another name, so the board is the concludis INSTANCE ID (`iid`), not a tenant label.** A posting is `/_/jobad?prj=<iid>P<position id>` and the position id is the one the employer's `<tenant>.concludis.de` list shows (Vitanas: iid 147, concludis position 130755, portal posting `147P130755`; 230 of the tenant's 231 positions are on the portal). The portal names a tenant's concludis label on no page it serves, so it reaches the employers the `concludis` adapter cannot — 590 iids against 23 labels. The external id is the whole `prj` value with the separator folded to `P` (harvested links spell `100007p36`). **Onboarding must skip the iids whose employers are already `concludis` boards**: the same position under two providers is a cross-source duplicate; check a sampled position id against `jobs.external_id` for `source = 'concludis'`.
- **The list is `/_/joblist?iid=<board>&page=N`, 25 lines a page, stating `Suchergebnis: <strong>N</strong> Treffer`**; a page past the end carries no line. The walk must reach exactly that count (`fullBoardListing`). An iid with no posting and an iid that does not exist both answer "Keine Ergebnisse gefunden", so neither is `ErrBoardGone`. A vanity label (`apetito-ag.helixjobs.com`) serves the same pages and is not the board.
- **The body is the posting page's JobPosting, in exactly the concludis shape** (`concludisJobPosting`: employer, workplaces with ISO countries, `employmentType` as one enum or a list), so this is a HydratingSource. A missing posting is 404. No sampled posting (119) states `jobLocationType`. **A posting the portal relays to another platform redirects off `helixjobs.com`** (iid 500000's postings land on a P&I LOGA site) and is dropped, the concludis rule.
- **One origin serves every iid**, so the whole provider shares 4 requests in flight (`helixjobsMaxInFlight`), the measured width; a first crawl is ~25k posting pages and outlasts one run.
