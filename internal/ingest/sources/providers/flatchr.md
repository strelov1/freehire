**Flatchr traps** (`flatchr`, a French ATS at `careers.flatchr.io/<lang>/company/<board>`; live-verified 2026-10-24 across 306 board slugs from remoterocketship and Common Crawl — 220 live, 5,558 published vacancies, 5,290 of them in France and ~1% technical):

- **The board is one unpaginated JSON document**, `careers.flatchr.io/company/<board>.json`, which the client-rendered careers site loads itself: every published vacancy with its three body sections (`description`, `mission`, `profile`) and its structured fields, so there is no detail request. It is read through `GetJSON` and never `GetText`: `albconciergerie` (2,264 vacancies) is 22 MB, past the text cap.
- **A switched-off careers site answers HTTP 200 with an HTML fragment** (`<section class="notFound">`, "Votre recherche est tombée à l'eau") at the `.json` address; an unknown slug answers a JSON 404. The adapter re-reads the address as text only when the JSON fails to decode, and only the fragment is `ErrBoardGone` — anything else that fails to decode stays an ordinary failure.
- **A board can be a holding's.** `additi`'s site lists its subsidiaries' vacancies (`medialex`, `regieradioregions`) beside its own, and the same vacancy id then appears on both boards, so the employer is each vacancy's `company.name`. The harvest prober takes the employer name only from a vacancy filed under the board's own company, so a subsidiary's name never trips the name gate.
- **`remote` is the telework enum**: `fulltime` → remote ("Télétravail total"), `parttime` → hybrid, `notime` → onsite. Measured: 22 of 37 `fulltime` bodies say "100% télétravail", 1,742 of 2,957 `parttime` bodies name a number of telework days.
- **Salary is not read.** `salary`/`salary_max` sit beside a period letter (`mensuality` y/m/h/d) that contradicts the amounts on sampled rows (`800-1200` filed yearly), so a structured salary would publish wrong figures; enrichment's own reading decides instead.
