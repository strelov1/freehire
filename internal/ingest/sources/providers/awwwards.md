**Awwwards Jobs traps** (`awwwards`; live-verified 2026-11-22 from the crawl host, plain HTTP):

- **Plain HTTP passes; `robots.txt` (`User-agent: *`) allows `/jobs/`.** It disallows `/gallery/`, `/search-websites`, `/submission/`, `/vote/`, `/tag/` and some account paths; none is requested. Its sitemap index (`/sitemap.xml/`) is not needed.
- **The listing is `/jobs/?page=N`, 12 postings a page, 17 in all (2 pages) on 2026-11-22** — a tiny board. A page past the end answers **404**, which ends the walk (any other error fails it). The site's filter pages (`/jobs/offer/`, `/jobs/search/`, `/jobs/full-time/`) are the same list or a subset of it; the plain listing is the whole catalogue and is the only one walked.
- **The external id is the slug** (`art-director-3`, from `/jobs/<slug>.html`); there is no numeric id. The adapter keeps the slug as the identity and the listed URL as the link.
- **Development postings are known from the site's own category page.** `/jobs/programming/` lists the postings the site files as development work (2 of 17 on 2026-11-22: a creative developer and a creative software engineer); only those carry `IsTechHint`. `/jobs/design/` and `/jobs/other/` are not hints (`other` held a manual QA tester). If the programming page cannot be read the crawl goes on with no hints rather than failing.
- **The posting page's schema.org JobPosting is the body**: `title`, `description` (Quill HTML, whose list items carry empty `ql-ui` spans that `sanitizeHTML` drops), `hiringOrganization.name`, `datePosted` spelled out as `November 03 2026` (parsed with `January 02 2006`) and `jobLocation.address.addressLocality`, which holds a country ("United Kingdom") or a city, free text either way. It states **no employment type and no work model**, so neither is set; the location dictionary reads the text.
- **Studios and agencies post here** (Lusion, Frontify, ...), so the board is an aggregator with the company read per posting. Titles are design-led (UI/UX, art direction, creative developer); expect a small `is_tech` share.
- **Cost: 3 listing requests plus one per new posting, paced at one a second.** Daily is plenty.
