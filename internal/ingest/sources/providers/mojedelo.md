**MojeDelo traps** (`mojedelo`, Slovenia's largest general job board; live-verified 2026-10-29 from a residential IP, not yet from the crawl host):

- **The site is an SPA over its own JSON API, `api.mojedelo.com`.** The search is `GET /job-ads-search?pageSize=&startFrom=` and a posting `GET /job-ads/<uuid>`; both answer 400 "Tenant header missing" without three headers, `tenantId`, `channelId` and `languageId` — public ids the site itself reads from `api.mojedelo.com/uploaded-files/config/www.mojedelo.com/jb.globals.js`, not credentials. No Cloudflare, no bot wall; the project's bare User-Agent is served. `robots.txt` disallows only the preview paths.
- **`pageSize` above 100 answers 500**, although the validator names 200 as the limit. So the whole catalogue is ~40 pages, each answering in ~7 s whatever its size — ~2.5–5 minutes a walk. The unfiltered order (promoted postings, then newest) is stable: a full walk read 3,960 distinct postings in 3,960 rows against a stated `total` of 3,963. Any page failing fails the crawl, as for computrabajo, since the adapter is swept by company.
- **A search row carries everything but the body**: title, employer, town, structured `country.countryCode`, the arrangement and the start date. The body (`jobDescription`, `weExpect`, `weOffer`, the posting's own `aboutTheCompany` — the "O podjetju" tab) is HTML on the posting resource, ~1 s a request, so the adapter is `CoverageGated`: new postings only, at most 1,200 a run, stopping 5 minutes before the deadline. A cold catalogue (~4k) takes four runs.
- **The employer profile rides on the posting resource too** (`company.websites`, `address`, `industry`, `vatNumber`, `aboutCompany`), but `Job` has no field for it and `CompanyDescriber` is per board, so only the posting's own about-paragraph is kept, in the body.
- **An anonymous posting names the site's operator** ("Styria digital marketplaces d.o.o.") and carries `anonymizedCompany`; it is dropped. The operator's OWN postings carry no such marker and are kept.
- **Not all of it is Slovenian**: on 2026-10-29 3,866 SI, 69 AT, a handful DE/HR/IT/PT/NL, and 17 with no country at all (agency postings for Germany, "Nemčija"/"München"). The country is the row's code; a row without one sets none. A posting without a town (126) states its place in free text (`jobLocationInput`, from "Tilmitsch ali Gleinstätten" to a list of 23 towns).
- **The arrangement is a multi-select**: one posting ticks "Od doma", "Hibridno" and "Na delovnem mestu" together, so only a single tick is read; "Na terenu" (fieldwork) has no counterpart. Only 846 of 3,960 tick any. The salary is a band picklist ("1501 - 2000 EUR Bruto", gross a month), read only as a closed band; "po dogovoru", "0 - 800" and "10000+" set nothing. "Študentsko delo" is a student-service contract, not an internship, and sets no employment type.
- **The IT category is not a tech signal**: "Računalništvo, Programiranje, IT" (157 postings) is one of up to three categories a poster ticks, and holds insurance agents, graphic designers and security technicians, so `IsTechHint` is not set.
