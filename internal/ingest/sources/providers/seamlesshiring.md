**SeamlessHiring traps** (`seamlesshiring`; live-verified 2026-10-31, tenants `letshego` 2 postings and `goldenoiltd` 9; emptied boards `coronationgroup` and `mgas` answer 200 with `data: []` and `total` 0; an unknown label is DNS NXDOMAIN, not an empty list):

- **A board is the tenant label** on `https://<tenant>.seamlesshiring.com`. The listing is `GET /v2/jobs/job-list?limit=100&page=` and needs no key. `next_page_url` is `http`, so the walk builds the next `https` URL itself and stops at `last_page`. The crawl fails unless `last_page` is `ceil(total/100)` (1 when total is 0), each page's `current_page`, `per_page` and row count match, and the distinct ids equal `total`, which is what earns `fullBoardListing`. A total above 50000 fails the crawl. A missing or null `data.jobs.data` fails the crawl. An emptied tenant was observed live, and an unknown label does not resolve, so the adapter claims `emptyBoardListing`. `www` and the apex answer HTML 200 (the marketing site); `Recognize` folds `www.` off before the host match, so both are the bare apex and not a board. The shared platform-label list also declines `app`, and `app.seamlesshiring.com` is a live tenant (9 postings the same day) that harvest will not record for that reason.
- **The list row is the whole posting.** `company.name` is the employer, else the catalogue company. `summary` is plain text and `details` is HTML. `job_type` is hyphenated (`full-time`, `part-time`). `work_style` `onsite` / `remote` / `hybrid` sets the work mode; a null style sets nothing. Place is `city` plus `location` when they differ. `location_details.country.country_code` is passed through `location.NormalizeCountry`; `NA` (Namibia, on Letshego) is not in that dictionary, so the facet stays empty and the place string is what remains. Pay is not stored: `currency_id` is an internal id (74 on Golden Oil) with no ISO code, even when `show_remuneration` is 1 and the amounts are filled. `created_at` is the posted time, then the date-only `post_date`. The job URL is `/job/view/<id>`.
